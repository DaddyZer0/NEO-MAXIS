# NEO-MAXIS Development Roadmap

This roadmap describes intended development stages. It does not imply that
planned features are already implemented.

## Phase 1 — Foundation
- Establish source control and project documentation.
- Stabilize the CMake build.
- Preserve reproducible test execution.
- Document sc2kfix integration requirements.
- Establish Windows and Linux development workflows.

## Phase 2 — Core Simulation
- Strengthen city session management.
- Formalize shared simulation state.
- Define event and lifecycle interfaces.
- Establish reliable save/load behavior.
- Expand automated testing.

## Phase 3 — Simulation Domains
- Expand economic simulation.
- Develop population and demographic systems.
- Develop infrastructure and transportation systems.
- Develop environmental and industrial systems.
- Investigate government and disaster mechanics.

## Phase 4 — Extensibility
- Define a versioned extension interface.
- Establish module registration and lifecycle rules.
- Document dependency and compatibility requirements.
- Provide example extensions.
- Develop migration and compatibility policies.

## Phase 5 — Community Release
- Prepare reproducible Windows builds.
- Publish installation and compatibility documentation.
- Establish contribution guidelines.
- Publish tested releases.
- Invite community testing and contributions.

## Guiding Rule

Each milestone should be independently testable and should preserve the
stability of previously completed work.
