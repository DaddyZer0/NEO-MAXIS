# Contributing to NEO-MAXIS

Thank you for your interest in NEO-MAXIS.

The project is experimental and its architecture is evolving. Contributions
should favor clarity, modularity, testability, and compatibility.

## Before Contributing

- Read the project README.
- Review the architecture and roadmap.
- Check existing issues before starting substantial work.
- Discuss large architectural changes before implementing them.

## Development Principles

- Keep modules focused on one responsibility.
- Prefer explicit interfaces over hidden dependencies.
- Avoid unnecessary platform-specific code in shared systems.
- Include tests for new simulation behavior where practical.
- Document assumptions and compatibility requirements.
- Do not include original commercial game assets or executables.

## Changes

Keep changes focused and explain:
- What changed.
- Why it changed.
- How it was tested.
- Whether Windows or Linux behavior is affected.

## Third-Party Code

Do not introduce third-party code or dependencies without checking their
licenses and documenting their origin.

## Project Direction

NEO-MAXIS aims to become an expandable community project. Contributors
should help preserve a codebase that future developers can understand,
test, and extend.
